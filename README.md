# 싸준

웹에서 알고리즘 문제를 풀고, 코드를 제출하고, 채점 결과와 제출 기록을 관리할 수 있는 온라인 코딩 테스트 연습 서비스입니다.

사용자는 별도의 IDE 없이 문제 확인, 코드 작성, 실행, 제출, 채점 결과 확인까지 하나의 웹 환경에서 진행할 수 있습니다.

## 주요 기능

### 사용자 기능

- 알고리즘 문제 목록 조회
- 난이도 및 알고리즘 유형 기반 필터링
- 문제 상세 페이지 확인
- 웹 코드 에디터를 통한 코드 작성
- 코드 실행 및 제출
- 채점 결과 확인
- 제출 내역 조회
- 제출 코드 다시 보기
- 같은 언어로 제출한 다른 사용자의 풀이 확인

### 관리자 기능

- 문제 생성, 수정, 삭제
- 문제 예제 관리
- 테스트케이스 관리
- 사용자 관리
- 제출 현황 확인

## 주요 개선 경험

### 홈 초기 진입 성능 최적화

홈 화면 진입 시 불필요한 KaTeX, 웹폰트, Markdown, RSC prefetch 요청으로 초기 로딩이 지연되는 문제가 있었습니다.

Lighthouse와 Turbopack Analyzer로 병목을 분석하고, 홈에서 사용하지 않는 전역 리소스를 제거했습니다. 또한 주요 링크의 prefetch를 제한하고, 사용자별 제출 데이터는 클라이언트에서 지연 로드하도록 분리했습니다.

그 결과 홈 초기 요청 수를 84개에서 27개로 줄이고, 전체 전송량을 약 836KB에서 210KB로 개선했습니다.

### 문제 상세 페이지 렌더링 구조 개선

문제 상세 페이지에서 문제 본문, 사용자 풀이 상태, 테스트케이스, 코드 에디터 로딩이 초기 진입 과정에 함께 얽혀 있어 핵심 콘텐츠 표시가 지연되는 문제가 있었습니다.

문제 본문은 Server Component에서 먼저 렌더링하고, 사용자별 풀이 상태는 `solve-state` API로 통합했습니다. 코드 에디터는 `dynamic import`와 skeleton UI를 적용해 초기 렌더링 경로에서 분리했습니다.

그 결과 FCP를 약 1.5초에서 0.3초로, LCP를 약 2.1초에서 0.3초로 개선했습니다.

### 문제 목록 API 응답 속도 개선

문제 수가 3,000개 이상으로 증가하면서 문제 목록 데이터가 늦게 표시되는 문제가 있었습니다.

기존에는 `/api/problems` 요청마다 제출 통계, 시도자 수, 해결자 수, 정답률, 사용자별 풀이 상태를 함께 계산하고 있었습니다.

공용 문제 데이터와 사용자별 풀이 상태 데이터를 분리하고, 문제별 통계는 `problem_stats` 테이블에 사전 집계하도록 변경했습니다. 또한 TanStack Query를 활용해 공용 문제 목록 캐시와 사용자별 상태 캐시를 분리했습니다.

그 결과 `/api/problems` 응답 시간을 약 7~8초에서 120ms 수준으로 단축했습니다.
